# Острова Ветра

Небольшая 3D-игра-прогулка по архипелагу парящих островов. Восемь островов
разной формы и высоты, многоуровневые террасы, тропинки, висячие мосты,
водопад и двенадцать спрятанных кристаллов.

## Запуск

Просто откройте `index.html` двойным щелчком в Chrome, Edge или Firefox.
Интернет не нужен: Three.js лежит рядом в `vendor/three.min.js`, все текстуры
и звуки генерируются в браузере.

Если браузер почему-то не загружает локальные скрипты, можно поднять
маленький сервер из папки игры:

```bash
python -m http.server 8123
```

и открыть `http://localhost:8123`.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` / `↑` | идти вперёд |
| `S` / `↓` | идти назад |
| `A` / `←` | повернуть влево |
| `D` / `→` | повернуть вправо |
| `Shift` | бег; в полёте — снижение |
| `Пробел` | прыжок; в полёте — подъём |
| `F` | включить / выключить полёт |
| Мышь (вертикально) | наклон камеры |
| Колесо мыши | приближение камеры |
| `R` | вернуться на ближайший остров |
| `M` | звук вкл/выкл |

На телефоне и планшете джойстик работает так же: влево-вправо — поворот,
вверх-вниз — движение вперёд/назад. Боком герой не ходит.

## Как играть

- Камера жёстко закреплена за спиной героя и поворачивается вместе с ним.
  Боком ходить нельзя: `A/D` поворачивают героя, `W/S` ведут вперёд и назад.
  На спусках и подъёмах камера немного меняет высоту и не проваливается
  под настил мостов.
- Идите по тропинкам: они выводят к мостам и поднимаются на верхние террасы.
- Висячие мосты соединяют острова; по ним можно перейти пешком. На мосту
  подпись «Мост на …» показывает остров в направлении взгляда героя —
  развернулся, и подпись меняется на противоположный берег.
- Кнопка «Летать» (или `F`) включает полёт. Энергия полёта показана полоской
  над кнопкой и восстанавливается, когда герой стоит на земле.
- На каждом острове есть светящиеся кристаллы. Соберите все двенадцать — и
  архипелаг будет исследован.
- Если упасть в облака, ветер вернёт героя на ближайший остров (как и `R`).

## Что внутри

- восемь огромных процедурных островов с пологим рельефом, широкими плато,
  мягкими холмами и каменными «корнями» снизу;
- высокие деревья в реальном масштабе — с толстыми стволами и кронами,
  под которыми свободно проходит герой;
- восемь длинных висячих мостов с досками, канатами, подвесами и фонарями;
- сеть тропинок с серпантинами и полками-рампами между уровнями;
- полёт с крыльями, струёй двигателя и запасом энергии;
- герой с анимацией бега, прыжка и полёта;
- водопад, пруд с лилиями, облака, парящие обломки и кристаллы;
- звук ветра, шагов и полёта, синтезированный через WebAudio;
- HUD, стартовый экран и адаптивная вёрстка для телефона.

## Структура

```
index.html        разметка, стили, HUD
src/terrain.js    генерация рельефа, текстур и троп
src/world.js      острова, мосты, декор, кристаллы, атмосфера
src/player.js     герой, физика, полёт, анимация
src/main.js       камера, ввод, UI, игровой цикл
src/audio.js      синтезированный звук
vendor/three.min.js  Three.js r160
```

Игра не требует сборки и не использует ES-модули — поэтому работает прямо с
локального файла.
